# TaskForge

A lightweight project management dashboard built with Vanilla JavaScript.

TaskForge is a learning-focused project designed to practice modern JavaScript concepts through a real-world application.

## Features

* Create tasks
* Edit tasks
* Delete tasks
* Change task status
* Filter tasks
* Search tasks
* Store tasks locally
* Restore tasks after page reload
* Task priorities
* Task types
* Form validation
* Error handling
* Responsive UI

## JavaScript Concepts

This project focuses on practicing:

* Classes and Object-Oriented Programming
* Prototype and Prototype Chain
* Inheritance
* DOM Manipulation
* Event Handling
* Event Delegation
* Array Methods

  * `map`
  * `filter`
  * `find`
  * `some`
  * `every`
  * `reduce`
* Async / Await
* Promises
* Fetch API
* Error Handling
* LocalStorage
* SessionStorage
* JSON
* Destructuring
* Spread / Rest Operators
* ES Modules
* `this`
* Closures

## Learning Goal

The main goal of TaskForge is not to build another task manager.

The goal is to understand how JavaScript works in a real application and to practice writing structured, maintainable code.
